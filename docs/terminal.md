# Навигация в терминале

Конфигурация — [navigation.zsh](../home/.oh-my-zsh-custom/navigation.zsh).
Oh My Zsh сначала подключает свой плагин `fzf`, затем пользовательский файл
добавляет предпросмотр, fzf-tab, fzf-simple-git и zoxide. Старый плагин `z`
и загрузка `~/.fzf.zsh` больше не используются.

## Установка и восстановление

`install_macos` / `install_linux` устанавливают fd, fzf, zoxide, difftastic,
bat и tree через системный пакетный менеджер. В Debian/Ubuntu пакеты fd и bat
могут предоставлять команды `fdfind` и `batcat`: конфигурация поддерживает оба
имени. Linux также устанавливает `bsdextrautils` с командой `column` для веток Git.
Нужен дистрибутив, в репозиториях которого доступны указанные пакеты.

`scripts/install_terminal` получает fzf-tab и fzf-simple-git в
`~/.local/share/dotfiles/zsh`. Переменная `DOTFILES_ZSH_PLUGINS_DIR` позволяет
изменить этот каталог; одинаковое значение должно быть доступно установщику
и интерактивному shell. Исходники плагинов не попадают в dotfiles.

Повторный запуск сохраняет существующие checkout, включая локальные правки,
и скачивает отсутствующие. Непустой повреждённый checkout требует ручного
разбора; установщик не удаляет его. Dotbot создаёт/исправляет симлинк
`~/.local/bin/dotfiles_previewer` и ссылку каталога `~/.oh-my-zsh-custom`.
При открытии shell нет установки или обновления из сети.

После установки откройте новый терминал. Отсутствующие зависимости выводятся
как сообщения `[dotfiles]` в stderr; остальная конфигурация продолжает работать.
Данные старого плагина `z` автоматически в zoxide не импортируются: новая база
пополняется при посещении каталогов.

## Файлы, история и каталоги

| Клавиши / команда | Действие |
|---|---|
| `Ctrl+R` | Нечёткий поиск по истории команд |
| `Ctrl+T` | Выбрать файл/каталог и вставить путь в командную строку |
| `Alt+C` | Выбрать каталог и перейти в него |
| `Tab` | Дополнение Zsh через fzf-tab |
| `[` / `]` в fzf-tab | Предыдущая / следующая группа дополнений |
| `Ctrl+H` в файловом меню | Показать / скрыть предпросмотр |
| `z dotfiles` | Перейти к часто посещаемому каталогу по части пути |
| `zi` | Интерактивно выбрать посещённый каталог через fzf |

На macOS для `Alt+C` терминал должен передавать Option как Alt/Esc.
В fzf-tab `Tab`/`Shift+Tab` перемещают выбор, `Enter` принимает дополнение,
`Ctrl+Space` отмечает несколько вариантов. Это отличается от обычных меню fzf,
где `Tab` используется для множественного выбора, если он включён.

fd учитывает `.gitignore`, включает скрытые пути и исключает `.git`, `.venv`
и `node_modules`. Предпросмотр показывает первые 150 строк файла через bat
или первые 100 строк дерева глубиной 2. Код просматриваемого файла не запускается.

Предпросмотр подключён к `Ctrl+T`, `Alt+C` и дополнению файловых команд
(`cd`, `ls`, `cat`, `cp`, `mv`, `vim`, `code` и др.). Глобальные
`FZF_DEFAULT_OPTS` конфигурация не меняет: `vrg` и fzf-меню Vim сохраняют
свои настройки. Встроенные функции fzf-tab и Git-плагина могут иметь свои клавиши.

## Git

| Последовательность в Zsh | Что выбрать для вставки в командную строку |
|---|---|
| `Ctrl+G`, затем `l` | Хеш коммита |
| `Ctrl+G`, затем `b` | Локальную ветку |
| `Ctrl+G`, затем `t` | Тег |
| `Ctrl+G`, затем `f` | Отслеживаемый файл |
| `Ctrl+G`, затем `]` | Справку плагина |

После `Ctrl+G` отпустите Ctrl и нажмите вторую клавишу без модификаторов.
Плагин поддерживает и варианты со вторым Ctrl, но `Ctrl+B` занят префиксом
tmux, поэтому в справочнике используются обычные буквы.

Одиночный `Ctrl+G` — только префикс: он ждёт вторую клавишу, а не открывает
меню. Его стандартная привязка Zsh `send-break` снята, чтобы пауза между
клавишами не вызывала beep и отмену командной строки. Для отмены есть `Ctrl+C`.

Например, наберите `git switch `, выберите ветку через `Ctrl+G`, затем `b`,
проверьте получившуюся команду и нажмите Enter. Сам выбор ветку не переключает.
В меню доступны множественный выбор по Tab и предпросмотр по Ctrl+H.
В меню коммитов/веток Ctrl+S открывает `git show`, Ctrl+D — `git diff`.
В правом окне предпросмотра `Shift+↑` / `Shift+↓` прокручивают diff;
обычные стрелки перемещают выбор в списке. В отдельном просмотре через less:
`j` / `k` — строки, `Ctrl+D` / `Ctrl+U` — половина экрана,
`Space` / `b` — экран вниз / вверх, `g` / `G` — начало / конец,
`q` — вернуться к списку. Здесь `b` нажимается без Ctrl и не конфликтует с tmux.
Git-предпросмотр через delta использует текущую ширину окна fzf
(`FZF_PREVIEW_COLUMNS`), включая изменение размера. За пределами preview
ширина определяется как обычно. Пользовательский `FSG_PAGER` не дополняется
параметрами delta.
В меню файлов Ctrl+E открывает файл в `$EDITOR` (по умолчанию `vim`),
Ctrl+J переходит к blame.

Встроенное открытие браузера по Ctrl+B использует `gh` и GitHub; эта возможность
не настроена для GitLab и не входит в набор устанавливаемых зависимостей.
В tmux это сочетание также перехватывается его префиксом.
Локальный поиск, предпросмотр и вставка Git-объектов не требуют `gh`.

`fetch.prune = true` удаляет устаревшие remote-tracking ссылки при fetch,
но не локальные ветки. Автоматическая очистка тегов не включена.

`git diff` продолжает использовать delta. Для синтаксического сравнения:

```sh
git difft
git difft --cached
git difft main -- path/to/file.py
```

Alias включает внешний diff только для этого вызова; глобальный `diff.external`
не устанавливается.

## Проверки

```sh
python3 tests/test_navigation.py
bash -n scripts/install_terminal home/.local/bin/dotfiles_previewer
zsh -n home/.zshrc
zsh -n home/.oh-my-zsh-custom/navigation.zsh
shellcheck -x scripts/install_terminal home/.local/bin/dotfiles_previewer
```

Тесты проверяют предпросмотр путей с пробелами, вычисление путей Vim,
неназванные/служебные буферы и повторное создание Git-checkout во временных
каталогах. HOME и системный clipboard не меняются. Проверка внутреннего регистра
выполняется только на Vim без `+clipboard`; другую сборку можно выбрать через
`VIM_BIN`. Установка пакетов Linux/macOS и интерактивные GUI проверяются отдельно.
